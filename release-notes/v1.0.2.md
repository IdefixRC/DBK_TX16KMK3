## Improvements

- `BatAlertPct` changed to a numeric input, making it easier to adjust with the scroller.
- Pilot name removed from the widget options and moved to a configuration file on the SD card.
- New `/WIDGETS/DBK_TX16KMK3_config.json` file, so settings persist outside the widget folder.
- Support for the `pilot_name`, `battery_alert_pct` and `battery_alert_interval` keys.
- The configuration file is created automatically with default values when it is missing or empty.
- Configuration is reloaded at runtime, so changes to the JSON take effect without recreating the widget.
- Configuration logic moved out of `main.lua` into `config.lua`, leaving the main file cleaner.
- Release workflow adjusted to package `config.lua` and the `audio` folder.

First release of this fork, based on v1.0.6.

## Model images

- The widget now uses **only** the image you assign to the model in EdgeTX **Model Setup**, loaded from `/IMAGES/`.
- The lookup based on the model name is gone. v1.0.6 first looked for `/IMAGES/<model name>.png`, ignoring a leading `>`, and only then fell back to the Model Setup image.
- **If you relied on the model name lookup, open each model in Model Setup and assign its picture.** Without that the widget shows its built-in default image.
- Model names are now free-form. The `>` prefix convention no longer changes anything.
- The two sample pictures that used to ship in `modelImage/` are no longer part of the package.

## Documentation

- The README and the release notes are in English, as are all comments in the script.
- New troubleshooting section covering two common cases: the flight controller not being detected in DFU mode while flashing, and the widget showing its default picture instead of a model image.

## Installation

- `deploy.sh` is removed. Install by copying the `DBK_TX16KMK3` folder onto the SD card, as described in the README.
- The VS Code deploy task is removed as well.
- The release package no longer carries `deploy.sh` or the `modelImage/` folder.

## Unchanged

Telemetry display, audio alerts, RGB LED control, the JSON configuration file and the performance work from v1.0.6 all behave exactly as before.

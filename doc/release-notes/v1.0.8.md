**IMPORTANT:** If you are migrating from an older version of this widget, please ensure
you open up and update the widget setting as values from previous versions are not
carried over correctly.

## Performance

Large performance improvements. The widget draws each frame with about a quarter fewer
screen operations and generates roughly 70% less garbage per frame, so it is lighter on
both the processor and the radio's memory.

Nothing about the display changes. Telemetry is still sampled and redrawn at the same
rate as before.

## Widget settings and documentation

- Every widget option now has a plain, readable name, and the options a pilot changes
  between flights sit at the top of the settings screen.
- Any option the widget cannot read falls back to its default, so the screen looks right
  from the first frame even before the settings are saved.
- The README documents each option, what `Log Switch` actually does, and the upgrade
  step described above.

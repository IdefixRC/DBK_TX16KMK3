## Model images

- Removed the requirement for a `>` prefix on the model name to find the matching image in `/IMAGES`.
- Kept compatibility with names that still use `>` as the first character.
- Added a fallback to the image configured in the EdgeTX Model Setup when no PNG matching the model name exists.
- Kept the internal default image as the last fallback.

## RGB LEDs

- Added options to pick the armed and disarmed state colours separately.
- Included the same ten colours available in StacyDash, with blue and red as the defaults.
- The `disable flags` animation now uses the colour chosen for the disarmed state.
- Added a check for the RGB API being available before driving the LEDs.

## Performance

- Gauge geometry, angles, colours and static text are now calculated once and reused.
- Digital displays now reuse dimensions, multipliers and divisors.
- Timer text is only formatted when the second changes.
- Colours configured in EdgeTX are only converted again when the option changes.
- LED animation intensity variations are now cached.
- Kept the same 10 FPS, drawing and telemetry behaviour as the previous version.

## Deploy

- Added the `-v` parameter to `deploy.sh` to query the ten most recent releases on GitHub.
- Added interactive selection, download and validation of the package before installing.
- The version selection mode can be combined with `--dry-run` and preserves logs and the external JSON file.
- `deploy.sh` is now part of the ZIP package published by the release workflow.

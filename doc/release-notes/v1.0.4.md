## Fixes

- Fixed the widget grabbing the interface when the screen is touched: it now leaves EdgeTX full-screen mode immediately, keeping the top bar and the `SYS` and `MDL` buttons available.
- Kept the widget redraw while leaving full screen, to reduce the flash of the system background.

## Performance and memory

- Reduced reloading of `/WIDGETS/DBK_TX16KMK3_config.json` from once per second to once per minute.
- Writing `config_debug.txt` is limited to widget startup, removing continuous writes to the SD card.
- Removed the buffers for the disabled RPM, current and voltage curves, which held up to 900 Lua entries in memory.
- Removed the generation of the auxiliary curve files belonging to that disabled feature.
- Constant tables for drawing, governor, LEDs, digits and audio are now reused across frames.
- Added a cache for the text and lines of the arming lock flags.
- Reduced the data kept by the temporary log write snapshot.
- Interface redraw limited to 10 FPS, while touch events are still processed immediately.
- Static gauge geometry is now calculated once and reused.
- Gauge arc draw calls cut from 270 to 144 per frame, preserving the visual thickness.

## Deploy

- Added `deploy.sh` for Linux, based on the StacyDash flow.
- Includes automatic EdgeTX card detection, a `--dry-run` mode and support for an explicitly given destination.
- Deploy limited to the files the widget uses, audio and model images.
- Flight logs and an existing `/WIDGETS/DBK_TX16KMK3_config.json` on the radio are preserved across updates.
- Documented the new deploy process in `README.md`.
